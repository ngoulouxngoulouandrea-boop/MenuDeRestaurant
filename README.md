# MenuDeRestaurant

## Description

Page statique de présentation du restaurant Saveurs du Congo. Le site présente un menu complet, des tarifs, les horaires d’ouverture, un formulaire de réservation et les informations de contact.

## Fichiers

- `index.html` : page principale.
- `styles.css` : styles de mise en forme.
- `images/` : dossier attendu pour les photos des plats.

## Fonctionnalités

- Navigation par ancres vers les sections du menu.
- Présentation des entrées, plats principaux, desserts et boissons.
- Tableau des prix par catégorie.
- Horaires d’ouverture.
- Formulaire de réservation statique.
- Informations de contact et adresse.

## Utilisation

1. Ouvrir `index.html` dans un navigateur.
2. Vérifier que `styles.css` est présent.
3. Placer les images utilisées dans `images/` si elles ne sont pas déjà présentes.

## Notes

Le HTML de la page utilise `lang="en"` tandis que le contenu est rédigé en français.
